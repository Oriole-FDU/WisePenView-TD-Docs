# 附件5   教学评语中的“人工智能使用表现”评价维度

建议嵌入课程期末评语、阶段性反馈、论文评价等场景。教师在评语中可结合以下维度，评价学生是否科学合理地使用人工智能工具，是否展现出主动思考与独立表达能力。

表 学生人工智能使用表现评价维度（示例）


| 维度 | 指标说明 | 等级描述（摘录） |
| --- | --- | --- |
| 工具规范性 | 是否合理选择工具，是否遵守课程及学校规范 | A：工具选择合理、用途清晰、披露完整；B：基本规范，偶有疏漏；C：规范意识弱；D：存在违规或严重不当使用 |
| 提示精确度 | 对人工智能的输入设计是否精准、明确，是否体现逻辑与思维深度 | A：提示词精准、逻辑清晰，能引导工具生成高质量输出；B：提示词基本合理，偶有模糊或低效；C：提示词设计较弱，输出依赖偶然结果；D：提示词不当或随意，严重影响输出质量 |
| 协作原创性 | 人工智能建议与个人思考的结合程度 | A：能有效整合建议，成果原创性高；B：部分依赖工具，个人贡献较为明确；C：依赖明显，个人加工有限；D：作品主要为工具输出，缺乏独立思考 |
| 批判辨识力 | 对工具输出错误与偏见的识别与修正 | A：主动发现问题并提出合理修正；B：能在提示下进行修正；C：识别能力较弱；D：基本无判断，照单全收 |
| 伦理合规性 | 对隐私、版权、公平等问题的认识 | A：高度重视并能自觉遵守规范；B：基本遵守，无明显违规；C：被动遵守，缺乏主动意识；D：存在明显不当行为或风险意识缺失 |


示例评语用语（可选）：

“能规范使用人工智能工具，披露完整，作品体现较强原创性和批判性。”

“较为依赖人工智能工具，建议加强独立分析与写作能力训练。”

“能设计高质量提示词，规范使用人工智能工具，成果体现较强原创性和批判性。”

“存在未披露使用人工智能情形，已进行谈话提醒，后续需重点关注。”

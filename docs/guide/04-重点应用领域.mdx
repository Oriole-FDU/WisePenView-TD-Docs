# 三、重点应用领域

在遵守本规范指引的前提下，鼓励各单位围绕以下重点领域推进应用探索，形成具有复旦特色的教与学新范式。

## （一）课堂创新与课程重构

智慧课程设计与实施。鼓励教师主动探索运用人工智能工具优化教学目标、活动与评价，推动以学为中心的课程创新与实践。教师可通过参加学校常年开设的“AI赋能的以学为中心课程设计”专题研修学习（内容大纲见附件1），也可使用智慧课程质量标准及其配套教程，开展课程自评（标准框架见附件2），实现智慧课程设计的迭代改进与质量保障。

课堂结构与教学角色升级。教师在保持课堂主导权的前提下，利用人工智能辅助完成教学情境创设、问题梯度设计、课堂练习生成、课堂例证补充等工作，把更多精力投入到课堂讨论、思维引导、生成结果校验与个性化反馈中，推动教学角色从“知识讲授者”转向“学习设计者、智能引导者”。

课程内容与学习活动重组。课程教学团队或课程组可在严格把关的前提下，引入人工智能辅助优化课程模块划分、学习任务设计与活动流程编排，构建“讲授—探究—展示—反思”更为紧凑连贯的学习闭环，增加师生互动，利用人工智能辅助教师引导学习过程。对通识课，可通过人工智能工具，融合不同学科特点生成多元案例与情境，加强课程的现实关怀和跨学科联系；对专业课，可借助人工智能工具迅速捕捉领域前沿，更新教学素材；对实践课，可以用人工智能设计编程与虚拟仿真环境，提供实时操作指导与反馈，帮助学生更高效地掌握实践技能，优化资源分配与实验流程。

资源建设与开放共享。在符合法律法规和版权要求的前提下，教师可使用人工智能辅助生成图文、习题、案例、情境对话、知识图谱等，用于建设课程资源库，辅助教育教学；教师可将已有课程内容、视频、作业等构建成高质量数据集；课程教学团队或课程组可对多位教师使用工具生成的资源进行筛选、重写与整合，形成具有课程风格的“复旦版”资源，避免“千课一面”。

## （二）学生自主学习与综合素养提升

自主学习支持。在课程要求许可范围内，学生可使用人工智能进行知识梳理、重点提炼、难点释义、练习生成等，将工具作为“助推器”提升学习效率。教师应在课程说明中明确人工智能的可用环节和禁止情形，引导学生将更多时间用于知识的理解、消化和内化，而非机械复制。促进学生从单纯的“工具使用者”向“人机协同决策者”转变。引导学生合理利用人工智能进行低阶认知负荷的卸载（如信息检索、格式整理），将精力聚焦于高阶思维能力（如批判性思维、复杂问题解决、审美与情感交互能力）的培养。

学术表达与国际沟通能力提升。对需要大量阅读、写作和外文材料处理的课程，学生应在严守学术规范前提下，规范使用人工智能进行语言润色、结构优化和初步翻译比对，从而提升学术表达与多语种沟通能力。学生应清楚哪些内容必须由本人独立完成，并按照要求披露相关使用情况。

综合育人与身心发展支持。在思想政治教育、生涯发展规划、跨文化交流等领域，教师可借助人工智能辅助构建贴近学生生活的情境案例，从而使学生在模拟对话、情景演练与反思写作中树立价值观、建立自我认同、提升沟通与协作能力。心理健康教育领域可使用工具辅助设计普及性活动与通识性材料，但不得替代专业评估与干预。

## （三）学业评价与反馈优化

课程考核结构优化。在课程考核设计中，鼓励通过过程性评价、形成性评价和终结性评价的组合方式，重点关注学生在分析、综合、创新等方面的真实表现。对允许使用人工智能的作业和项目，可适度把“工具选择与规范使用、人工干预与反思质量”等纳入评价维度，引导学生规范用智、善用智。鼓励利用学习分析与数据可视化技术，对课堂中学生与AI的交互过程进行“伴随式采集”与“画像建模”。通过知识图谱、能力雷达图等可视化手段，直观呈现学生的思维路径与能力短板，实现从“单一分数评价”向“多维能力评价”的转型。

批改与反馈方式创新。教师可在明确标准与范围的前提下，利用人工智能辅助完成客观题解析生成、结构化主观题要点匹配、班级共性错题分析等，减轻重复性工作压力。对作文、报告、论文等开放性任务，可先利用工具生成初步结构或语言建议，再由教师审核并进行有温度、有针对性的深度评价。

质量诊断与教学改进。在数据脱敏和合规前提下，课程组和院系可围绕某一课程或课程群，试点使用人工智能对作业、测验和课堂表现进行聚合分析，识别共性问题、结构性偏差，为教学改革和课程调整提供依据。鼓励教师利用人工智能技术进行学生学习记录，辅助教师评估学生学习状态。相关结果用于教学改进和学生支持，不得简单用于贴标签或固定分层。

## （四）教学管理与服务优化

班级管理与课程运行提效。任课教师可使用人工智能辅助撰写通知、活动方案、学习小结和班级周报，并在此基础上进行人工精简和个性化加工，提高日常沟通质量与效率，避免“格式化、模板化”。

教学管理运行优化。在确保信息安全和流程规范的前提下，教学管理部门可将人工智能作为提升日常事务处理效率的辅助工具，用于材料整理、信息比对、结构优化和格式规范等非实质性环节。对需要专业判断、政策解释或涉及制度效力的内容，应由工作人员完成关键内容的撰写与审核，确保管理文本的准确性、严谨性与权威性。各单位可根据实际建立适度的内部审核机制，保证人工智能参与的管理工作可控、可溯、可监督。

学情反馈与公共服务。教师可使用人工智能生成学情简报、阶段性反馈草案，但须结合学生实际情况进行审核修改。教学服务部门可使用工具优化常见问题解答、服务说明文本和多语种信息发布，提高信息获取的友好度和可达性，可为教师教育教学及学生自主学习提供参考信息和建议。

## （五）教师发展与教育研究赋能

教学反思与案例提炼。教师可以用人工智能来整理教案、课堂实录、学生问卷等资料，辅助梳理课程结构、提取高频互动模式、识别改进点，形成更有结构的教学反思。通过不断循环“设计—实施—反思—再设计”，推动个体经验提炼为可分享、可传播的教学案例。

教学技能训练与情境演练。通过设定典型教学场景（如课堂突发状况、跨文化交流等），由人工智能扮演“有经验的教师”或者“学生”等角色，帮助教师在低风险环境中反复演练提问技巧、反馈策略和沟通方式，提升课堂掌控力和复杂情境应对能力。

教育研究与校本教研。教师可利用人工智能辅助完成研究选题梳理、文献图谱初步构建、问卷草案生成、访谈提纲整理和结果可视化展示等。教研团队可使用工具整理教研记录、生成研讨提纲和方案对比表，提升教研活动的组织与产出质量。研究过程中应始终坚持阅读和独立分析原始文献，不得以生成内容替代自身的学术研究与思考过程。

## （六）学生科创项目提质

通过文献检索优化项目选题与方向。教师可以指导学生通过人工智能分析学术文献、行业趋势和科研数据，从而较快找到前沿且有价值的研究方向。但须确保所引用文献的真实性和可靠性。

数据收集与分析。教师可以指导学生使用人工智能辅助收集和处理数据，进而学习高级数据分析方法，在数据挖掘中形成更深层次的洞见。

人机协同创作可视化图表。教师可以指导学生使用人工智能工具推荐统计图表类型和辅助制图，但不得用于生成或修改原始研究数据及关键的研究图表，更不得用于美术设计等以图表本身为考察内容的课题文本中，且应确保最终图表的原创性与准确性。

实验设计与模拟。教师可以指导学生使用人工智能设计虚拟实验环境，使学生在低成本、低风险的情况下进行实验模拟。通过优化算法，提供实验参数的最佳组合，提升实验效率和成功率。

非创新性方法的人工智能工具辅助。当研究方法不属于课题的创新内容时，学生可以使用人工智能工具辅助程序代码编写、调试和错误排查，允许使用人工智能工具辅助统计学方法、实验方法、调研方法等研究方法的筛选与推荐，但应确保最终代码或研究方法的逻辑性、准确性、科学性和可维护性，所有代码或研究方法须经过作者审核和测试。

参考文献格式整理。在课题文本的撰写过程中，学生可以使用人工智能工具进行参考文献格式的规范化检查和自动排序，但须对生成内容进行核查。

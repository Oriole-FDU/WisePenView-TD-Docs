# 附件2        高等教育智慧课程质量标准框架


| 大类标准 | 具体标准 |
| --- | --- |
| 1.学习引导 | 1.1向学生明确说明应该如何开启课程学习。 |
|  | 1.2向学生介绍本课程的目的和学习进程安排。 |
|  | 1.3明确说明学生必须遵守的课程规则。 |
|  | 1.4明确说明学习课程应具备的学科知识与AI技能。 |
|  | 1.5教师、学生在网上提供恰当的自我介绍。 |
| 2.学习目标 | 2.1学习目标是一系列可衡量的学习结果，并从学生容易理解的角度加以描述。 |
|  | 2.2课程学习目标反映在课程各单元的目标设计中。 |
|  | 2.3明确解释学习目标与课程活动之间的关系。 |
|  | 2.4学习目标符合课程类型和水平。 |
| 3.学习测评 | 3.1学习测评能衡量学生是否达到规定的学习目标。 |
|  | 3.2明确说明课程成绩的评定规则。 |
|  | 3.3为学生提供评估其学习行为和产出成果的具体标准，并说明与评分的关系。 |
|  | 3.4测评应多种多样，包含AI参与的测评。 |
|  | 3.5 AI能提供有益的反馈让学生了解自己的学习进展。 |
| 4.教学资源 | 4.1课程教学资源有助于学生达到既定学习目标。 |
|  | 4.2.明确说明教学资源的目的以及它与学习活动的关系。 |
|  | 4.3课程教学资源不过时且多种多样，AI能推荐资源。 |
|  | 4.4教学资源都要正确标注来源，引用得当。 |
|  | 4.5明确解释必学资源和选学资源之间的区别。 |
| 5.课程活动 | 5.1学习活动有助于学生达成课程既定的学习目标。 |
|  | 5.2学习活动为学生提供互动机会, 引导主动学习。 |
|  | 5.3明确说明教师答疑和作业反馈等规划，并体现AI技术的应用。 |
|  | 5.4学习活动应多种多样，体现AI赋能的个性化学习路径。 |
|  | 5.5明确AI如何参与学生互动。 |
| 6.课程技术 | 6.1课程技术有助于学生实现学习目标。 |
|  | 6.2课程技术有助于学生积极参与，主动学习。 |
|  | 6.3课程使用的技术充分体现AI赋能。 |
| 7.学习支持 | 7.1明确说明提供的技术支持服务、学术支持服务以及它们的获取方式。 |
|  | 7.2学生容易获取课程所用的技术，明确AI技术的说明。 |
|  | 7.3为满足不同学生的学习需要，课程学习资源有不同的呈现形式，体现AI技术的支持点。 |
| 8.课程制作 | 8.1课程整体呈现清晰，融合智能技术增强课程学习引导。 |
|  | 8.2视频制作恰当，能激发学生参与。 |
|  | 8.3各种文本资料可读性强，支持学生高效学习。 |
|  | 8.4 AI助手设置合理，体现课程特色，支持个性化学习。 |

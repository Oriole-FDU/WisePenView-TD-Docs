# 四、规范指引

本部分明确全校师生在使用人工智能过程中的行为边界和底线要求，适用于课堂教学、课程作业、毕业论文（设计）、师生共创项目等各类场景。

## （一）信息保护规范，严守安全底线

严禁上传和爬取敏感信息。不得向人工智能工具和平台上传含有个人隐私、学生档案、科研机密、内部文件等敏感信息，特别是身份证件号码、联系方式、家庭住址、成绩和健康记录、未公开科研数据和内部会议纪要等。

优先使用安全平台。优先使用学校统一部署或经安全评估的人工智能平台和工具。各单位应根据实际建立数据使用登记和必要的访问记录，做到来源可查、去向可追、责任可究。

审慎开展跨境使用。使用境外或存在数据跨境传输风险的公共平台时，应重点核查其隐私政策、数据存储位置和传输路径，严格遵守国家相关法律法规。

## （二）学术诚信规范，坚守原创底线

坚守原则底线。人工智能工具可用于资料整理、语言润色、图表或代码初步生成等非核心创造性工作，不得替代研究思考、理论构建、数据分析、结论形成等实质性学术劳动。特别是不得直接使用人工智能工具生成课程论文或课题文本。

建立使用披露机制。凡在论文、报告、作业、课题文本、项目成果中使用人工智能工具的，应按要求说明工具名称、使用环节和人工干预情况，在文末附“人工智能使用声明”，做到“应披尽披、真实完整”，具体格式可参照《人工智能使用声明模板》（附件3）。

严格认定学术不端。将利用人工智能实施抄袭、捏造数据、代写代做等行为纳入学术不端和考试违纪认定范围，做到同责同罚、严肃处理。

## （三）知识产权规范，维护权利边界

依法使用受保护内容。使用人工智能生成、改写或处理的文本、图片、音视频等内容，如涉及他人作品或受保护素材，应依法引用，规范标注，不得通过技术手段规避或模糊权利归属。

合理界定成果归属。明确人工智能不具备作者资格。涉及人工智能辅助创作的成果，应综合考量提示词设计、内容筛选、结构构思、实质修改等人类投入及贡献，合理界定作者范围和署名顺序，维护个人、团队与学校的合法权益。

规范发表与转化使用。拟发表、出版、展览或用于成果转化的人工智能相关成果，应在成果说明中如实披露人工智能参与情况，按照有关规定办理权利授权、成果登记等手续。

## （四）社会责任规范，突出价值导向

坚持正确舆论导向。严禁利用人工智能工具生成、传播违法违规、有害信息以及违背社会主义核心价值观的内容，严禁通过人工智能放大偏见、歧视、谣言和恶意操纵信息。

强化主体责任担当。教师对其引入课堂和在课题指导过程中使用的人工智能内容负有审核责任，学生对其提交成果中的人工智能内容负有审核责任和真实性责任，不得以“算法自动生成”为由推卸责任。

注重公共伦理和社会影响。鼓励在相关课程、实践中，将算法偏见、信息安全、技术伦理等议题纳入讨论，引导师生正确理解技术边界，增强公共意识、法治意识和风险意识，引导人工智能更好服务教育公平和社会公共利益。教师和学生在实践中可参照《人工智能伦理风险自查清单》（附件4）开展自查自评。

## （五）坚持育人主体地位，构建良好学习生态

明确教师育人主导作用。在价值观引导、道德教育、情感培养、心理支持等关键育人环节，教师须亲自设计和实施，不得交由技术替代。

明确不同阶段学生的使用边界。各类课程应根据学生年级特点和认知水平，明确说明人工智能允许使用和禁止使用的环节。原则上禁止学生在闭卷考试、随堂测验等明确限制条件下调用相关工具；对低年级学生，要特别强调人工智能不能替代基础能力训练。

规范作业与项目使用。任课教师在布置作业、项目和论文时，应提前说明是否允许使用人工智能，以及允许使用的具体方式和披露要求。学生使用人工智能辅助完成观点表达或作品创作时，应明确标注所用工具、使用环节及生成内容，确保过程透明、诚信使用。

科学评价学生表现。教师在评价学生学业表现时，应重点关注学生是否科学、规范、诚信地使用人工智能工具。为支持教师开展评价，学校提供《教学评语中的“人工智能使用表现”评价维度》（附件5）作为参考。教师可在期末评语、阶段性反馈、论文评价等场景中，有意识地关注并简要评价学生在工具选择规范性、人机协作与原创性、批判性识别能力、伦理合规意识等方面的表现。

建立人工智能使用的规范认定与教育机制。对师生在使用人工智能过程中出现的不当或违规情形，应坚持“教育为先、规范为本”的原则，结合事实依据与情节轻重，采取分类处理方式。对轻微情况，可通过个别提醒、补充说明、学习规范要求等方式予以教育引导；对影响教学秩序或涉及学术不端的行为，应按照学校相关规定开展认定与必要处理。在处理过程中，应注重规则说明与教育引导，引导师生正确理解人工智能使用的边界与责任，共同营造诚信、规范的学术与学习环境。

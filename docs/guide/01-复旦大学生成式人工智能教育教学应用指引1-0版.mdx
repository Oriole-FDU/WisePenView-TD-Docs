# 复旦大学生成式人工智能教育教学应用指引1.0版

为深入学习贯彻习近平总书记关于教育的重要论述，贯彻落实全国教育大会精神和《教育强国建设规划纲要（2024—2035年）》要求，按照《关于深入实施“人工智能+”行动的意见》、《教育部办公厅关于组织实施数字化赋能教师发展行动的通知》、《教师生成式人工智能应用指引（第一版）》等文件有关精神，结合复旦大学教育教学改革实际，推动生成式人工智能（亦称“AI”）在教育教学中的科学、安全、合规、创新应用，构建具有复旦特色的人工智能赋能教育教学实践体系，特制定本实施指引。

本指引由复旦大学人工智能教育教学创新中心（简称“AI教创中心”）和复旦大学教师教学发展中心（简称“教发中心”）联合编制，面向全体师生，强调“共识共建、伦理先行、实践导向”的基本原则，配套提供教学应用范例、伦理行为指引、人工智能使用声明模板等附件材料，供各单位参照使用。

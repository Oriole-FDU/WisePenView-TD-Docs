# 六、施行与解释

本应用指引自发布之日起施行，由学校AI教创中心与教发中心共同负责解释。

为便于本指引落地实施，学校依托AI教创中心建设AI3A平台，作为生成式人工智能教育教学应用的统一服务入口，集中发布AI教学助手使用指南、典型教学应用案例、师生共创项目信息、教师研修资源以及人工智能工具清单等内容。相关资源由平台统一维护并动态更新，师生可通过学校官方渠道（https://ai4e.fudan.edu.cn）访问。本指引所列附件与平台资源相互配套，共同构成生成式人工智能教育教学应用的支持体系。

各院系可参考本指引，结合本单位学科特点和人才培养定位，探索制定适合本单位的实施细则或操作方案，明确本单位的重点任务、工作流程和职责分工。相关方案可向学校AI教创中心与教发中心报送，促进交流互鉴，并根据实践情况适时修订完善。

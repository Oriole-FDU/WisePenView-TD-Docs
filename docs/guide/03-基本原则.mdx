# 二、基本原则

## （一）坚持立德树人，服务国家战略

把人工智能应用统筹纳入学校人才培养体系整体设计，突出服务国家重大战略需求，服务教育强国建设，服务学生全面发展。引导技术应用始终服从和服务于立德树人根本任务，落实“技术向善、教育优先”的价值导向。

## （二）遵循教育规律，促进学生发展

坚持“以学生为中心、以能力为核心、以成效为重心”，尊重教育教学规律和学生成长规律，充分发挥人工智能在知识学习、能力培养、素质提升中的赋能作用，重点支持高阶思维、跨学科能力和创新能力发展，促进学生学会使用工具、善于驾驭工具、警惕依赖工具。

## （三）恪守伦理规范，强化风险防控

将数据安全、学术诚信、知识产权和科技伦理等要求贯通于人工智能应用全过程，健全伦理自查、自律与监督机制，提升全体师生对算法偏见、信息安全、隐私保护等风险的识别与防控能力，守牢意识形态安全底线和教育公平底线。

## （四）加强协同共治，推动均衡发展

坚持系统谋划，统筹顶层设计与基层探索、制度规范与技术支撑、试点先行与全面推广，推动教学、科研、管理、服务等多元主体协同共治，促进不同学科、不同类型课程间的均衡发展与良性互动。

## （五）坚持安全可控，注重可持续发展

把人工智能纳入学校信息化与教育治理体系，完善工具准入、安全评估与应急处置机制，坚持“凡进课堂必可控、凡入评价必可溯、凡涉数据必合规”，在确保安全、合规、可控的前提下稳步推进规模化应用，形成可持续迭代优化的智慧教育生态体系。

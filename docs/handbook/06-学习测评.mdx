## （二）为每个评价环节明确AI使用规则

引导：为（一）中选择的每个评价方式，确定AI融入的等级，即："这个环节中，学生能不能用AI？用到什么程度？"

请参考，示例：


| 评价方式 | AI融入等级 | 披露要求及方式 |
| --- | --- | --- |
| 1. | □ L0禁止使用AI |  |
| 2. | □ L1有限允许，需披露 | 需披露/书面声明 |
| 3. | □ L2鼓励使用 | 需披露 |
| 4. | □ L3要求使用 | 需披露 |


💡 提示，请注意：

"禁止"不等于"不信任学生"，而是保护某些能力的训练空间（如限时写作、即兴表达）。

"允许，需披露" 建议要求学生附简短说明：用了什么工具、用在哪个环节、自己做了哪些修改。

"鼓励使用" 适用于考察人机协同能力的环节（如项目报告、数据分析）。

“要求使用”适用于需重点考察AI能力的环节，如代码编写等

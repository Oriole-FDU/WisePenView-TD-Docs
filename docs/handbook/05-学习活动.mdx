## （二）主要活动简述（要求：对每个学习活动应明确标注其AI融入等级，使学生对预期有清晰认知）

引导：请根据以下的AI融入等级标注来填写教学活动设计表

### 1、AI融入等级标注


| 融入等级 | 说明 | 示例 |
| --- | --- | --- |
| Level 0：无AI | 完全人工完成 | 闭卷考试、口头答辩 |
| Level 1：AI辅助 | AI作为参考工具 | 用AI查找文献，人工筛选与评述 |
| Level 2：AI协作 | 人机共同产出 | AI生成初稿，人工深度修改与论证 |
| Level 3：AI驱动 | AI为主要执行者，人做决策 | AI完成数据分析，人解读与决策 |


💡 重要说明：

不是所有活动都需要AI：L0（无AI）同样重要，请注重运用LO来保护学生核心能力培养。

建议在教学活动中设置适当的L0环节，请确保学生有"脱离工具独立思考"的训练。

当教师在教学活动中设置AI融入为1-3的等级时，需为没有条件或不愿意使用AI工具的学生设置可以不使用AI工具完成任务的替代方案。

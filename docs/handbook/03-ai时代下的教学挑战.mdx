# 二、AI时代下的教学挑战

## （一）课程教学挑战的整体诊断

填写指引： 请结合本课程的学生特点、课程性质、先修衔接、学时安排等，识别在AI时代下，当前教学中最突出的2-3个核心挑战。

引导,请思考：


| 维度 | 问题 |
| --- | --- |
| 学生起点 | 本课程学生的知识基础、能力水平、学习动机如何？与先修课程的衔接是否顺畅？ |
| 课程难点 | 学生在本课程中最容易"卡住"或"掉队"的环节是什么？原因是什么？ |
| 教学条件 | 学时、班级人数、实践条件、平台资源等是否存在制约？ |
| AI带来的新变量 | 在上述背景下，生成式AI的普及使哪些原有挑战加剧了？又带来了哪些新挑战？ |


## （二）.AI相关挑战的聚焦分析

### 1、引导： 请从上一步识别的挑战中，选取与AI关联最紧密的1-2项，进行深入分析。

挑战描述：用1-2句话概括

示例：挑战描述：学生习惯用AI直接生成作业答案，导致我无法判断其真实理解程度。

归因分析：为什么会出现这个问题？

示例： 是评估方式的问题？是学生能力的问题？是AI工具太"好用"的问题？还是课程任务设计本身缺乏区分度？

应对思路：您打算如何调整？

示例：

1）是调整任务设计（让AI难以直接完成）？

是调整评估方式（从结果评价转向过程评价）？

是调整能力培养（教学生如何正确使用AI）？

还是调整规则边界（明确禁止/允许的范围）？

或者以上几项的组合及其他？

请参考示例：

示例使用提示：

不必逐项应对。可参照分析与您的课程面临的1-2项AI技术带来的挑战，在学情分析中深入展开即可。

归因比应对更重要——先想清楚"为什么"，再决定"怎么办"。

应对策略不是照搬清单，而是结合您的课程特点做适配。


| 挑战 | 归因（为什么会这样？） | 应对策略 |
| --- | --- | --- |
| 学生过度依赖AI，批判性思维与写作能力弱化 | 任务设计缺乏区分度，AI可直接生成"看起来正确"的答案；学生缺少"不用AI也能完成"的训练机会 | 对比报告：提交AI初稿+个人重构版② 找茬练习：识别AI输出中的错误与漏洞 ③ 设计情境化、开放性任务 |
| 评价真实性受冲击，作业/习题/代码易被AI完成 | 标准化任务占比过高；重结果轻过程；缺乏现场验证环节 | ① 增加过程性材料（草稿、迭代记录） ② 部分考核转为课堂限时完成 ③ 融入个人经验或课堂特定讨论 |
| 学术诚信与伦理风险（数据安全、知识产权、算法偏见） | 学生缺乏AI伦理意识；课程未明确使用边界；缺少数据安全教育 | ① 首周明确数据红线（什么不能上传） ② 伦理自查清单作为作业附件 ③ 组织算法偏见案例研讨 |
| 人机协同能力不足，提示词设计与输出核查能力弱 | 学生将AI当"搜索引擎"用，缺乏结构化使用训练；课程未提供方法论指导 | ① 提示词对比实验（同一任务不同提示词） ② 建立班级优质提示词库 ③ 将提示词质量纳入评分 |
| 面对面协作与深度互动弱化 | 学生习惯与AI"一对一"交互，减少同伴讨论和师生深度对话的动力 | ① 设置无设备协作环节（即兴辩论、白板推演） ② 口头答辩+随机提问 ③ 结构化同伴互评 |
| 工具可及性与数字鸿沟 | 商业工具存在付费门槛；不同学生设备条件差异；平台数据安全合规性不明 | ① 优先使用学校统一部署的平台 ② 为困难学生提供替代方案 ③ 提前评估商业工具数据合规性 |
| 教师AI素养与课程治理能力不足 | AI迭代快，教师缺少系统培训；课程组缺乏AI教学经验交流机制 | ① 参加学校AI教学研修 ② 课程组集体备课与经验分享 ③ 邀请同行听课指导 |
